# Wann hast du Zeit?

- Umfrage: `/zeit/` (optional `?fuer=kaffee|geburtstag|party`)
- Termin festlegen: in `termin.json` z. B. `"termin": "2026-12-05T19:00"`, `"fuer": "party"`, `"ort": "…"` eintragen.
  Dann sehen alle mit dem alten Link automatisch den Termin mit „In Kalender eintragen“ (Erinnerung 1 Tag und 2 Std. vorher).
- Leeres `termin` = wieder Umfrage. `?umfrage=1` zeigt immer die Umfrage.
